# JTB × 宇宙 — 納品ファイル

2026年9月10日作成。ビルド不要のHTML・CSS・JavaScriptと、画像・SVG・Webフォントの一式です。

## 表示方法

`index.html`をブラウザーで開くと表示できます。Webサーバーに配置する場合は、**このフォルダーの中身を階層ごと**アップロードしてください。サブディレクトリーへの配置にも対応しています。

Figma、Google Fonts、CDNなどへの通信は表示時に発生しません。React、Next.js、jQuery等は使用していません。

```text
site/
├── index.html
├── css/style.css
├── js/main.js
├── assets/
│   ├── images/    写真・透過ロゴ（WebP）
│   ├── icons/     Figmaのベクターアセット（SVG）
│   └── fonts/     WOFF2と各書体のライセンス
└── README.md
```

## 実装内容

- EARTH × SPACE・DOMAIN・NEWSは、表示領域へ入ると見出しから内容へ順にフェードアップします。一度表示した要素は再び隠しません。
- ホバー可能な環境では、SIDEのタブ・選択カード・矢印、DOMAINの詳細行、NEWSの各行に小さな移動・色・影の変化を付けています。

- 高度の背景画像は、各画像へ切り替わった時点から経過時間に合わせてゆっくり拡大します。スクロールを止めても拡大を続け、同じ背景内の逆スクロールでも縮小しません。次の背景は元の大きさから拡大を始めます。長時間停止しても構図が崩れないよう、拡大幅8%へ緩やかに近づく動きにしています。
- VISIONの最後の文章とEARTH × SPACEの間に、月面背景を保った余白を追加しました。

- 修正④：EARTH × SPACEの初期選択をCONNECTに変更。初回表示からCONNECTのタブ、カード、打ち上げ背景を同期します。
- 修正⑤：本文および和文見出しをGothic A1からNoto Sans JPへ変更。Gothic A1は表示時に読み込みません。
- ページ内メニューの黒い背景とぼかしを外し、透明背景に変更しました。
- 高度体験の中央コピーとPCの高度ナビは、固定ヘッダー・メニューより下の表示領域を基準に縦中央へ配置しました。SPの高度ナビは既存の下部配置を維持します。

- 修正③：38万km・VISION・DOMAINで一つの月面背景を共有。38万kmの構図・明るさを保ち、VISIONへの移行中やDOMAINの詳細開閉でも背景が切り替わりません。

- 修正②：「地上から約 〇〇km」を高度体験の共通表示として画面中央に固定。背景・コピーのフェードから独立させ、ラベルと数値欄の位置を保ったまま数値のみを更新します。VISIONに進むと高度体験と一緒に固定を解除します。

- 修正①：共通ヘッダーと、その下のTOP／VISION／DOMAIN／NEWS／CONTACTメニューを全区間で固定表示。本文・フッターまで移動しても表示と操作を維持します。
- ページ内移動時は固定領域を考慮して見出しの位置を調整します。VISIONは固定領域より下に文章を収めます。

- 同じHTMLをPC・SPで使用。本文は767px以下でSPレイアウトに切り替え、間の幅は自然に補間します。共通ヘッダーの外観は1199px以下でコンパクト表示になります。
- SPの高度背景は動的ビューポート高（`100dvh`）へ追従します。Safari等でアドレスバーが開閉して表示領域が変わっても、背景写真を画面下端まで維持します。非対応ブラウザーでは`100vh`へフォールバックします。
- Heroのコピー出現と、スクロールで前面の暗幕を薄くする演出。
- 地上→10km→25km→100km→400km→38万kmの背景切り替え、数値カウント、コピーの出現。
- 高度ナビは左側。選択中の高度を同期し、PCではアイコンが移動します。SPではアイコンを表示しません。
- SCROLL DOWNと縦書きのJTB × SPACE BUSINESSは高度体験の区間で追従し、VISIONに入るところで解除します。縦書きラベルは高度体験が始まってから表示します。
- VISIONは一つの文章に対し、スクロール順に文字を明るくします。修正③により背景の拡大率は固定しています。
- EARTH SIDE／CONNECT／SPACE SIDEのタブと矢印で、カードと指定背景を一緒に切り替えます。初期選択はCONNECTで、自動再生はありません。
- DOMAINの4項目は独立して開閉でき、コメントに記載された詳細本文・想定領域を収録しています。
- NEWS 7件、PROJECT、CONTACT、ページ内ナビ、共通ヘッダー／フッターの外観を実装しています。

## 確定済みの仮対応

**外部リンクは依頼どおり未接続です。** ページ内ナビ、高度ナビ、SIDE切り替え、DOMAIN開閉は動作します。

| 対象         | 納品時の状態・導入時の対応                                                                                     |
| ------------ | -------------------------------------------------------------------------------------------------------------- |
| NEWS         | 日付・カテゴリー・記事タイトルの外観。公開時に各記事のURLを設定                                                |
| PROJECT      | `data-link-pending="project"`のCTAをリンクに変更。指定元で確認した遷移先は `https://open-universe-project.jp/` |
| CONTACT      | `data-link-pending="contact"`のCTAを問い合わせ先へのリンクに変更。フォーム本体は対象外                         |
| 共通ヘッダー | `data-common-header`を付けた`header`を、導入先の既存コンポーネントに差し替え                                   |
| 共通フッター | `data-common-footer`を付けた`footer`を、導入先の既存コンポーネントに差し替え                                   |

未接続のCTA・共通部分は静的な要素です。空の`href="#"`、押しても反応しない仮ボタン、仮の検索・メニュー機能は設けていません。CTAを接続する際は外側の`span.cta`を`a.cta`に変更し、確定した`href`を設定してください。

## 文字・写真を修正する場所

- **記事・コピー**：`index.html`。`news-row`、`domain-item`などの名前を付けています。DOMを追加・修正した後にビルドする必要はありません。
- **デザイン共通値**：`css/style.css`冒頭の`:root`。色、幅、余白、フォント、角丸をまとめています。
- **高度の画像**：`altitude-*.webp`は各`altitude-scene`の`img`を差し替えます。`moon-surface.webp`は`.lunar-background`で一度だけ指定し、38万km・VISION・DOMAINで共用しています。
- **SIDEの背景**：`side-earth.webp`＝街並み、`side-connect.webp`＝スペースシャトル打ち上げ、`side-space.webp`＝地球と宇宙飛行士。
- **リンク接続後**：必要な外部リンク・共通コンポーネントの動作は、導入先の環境で確認してください。

| ---------------------------------------- | ------------ |
| 本文・和文見出し・共通ヘッダー／フッター | Noto Sans JP |

和文の指定は`"Noto Sans JP", sans-serif`です。Gothic A1の定義はCSSから削除し、表示時に読み込まない構成へ変更しています。

## アニメーションの調整

`js/main.js`の次の定数を変更できます。秒数・距離の詳細はデザインコメントに数値指定がなかったため、試作値です。

| 設定               | 現在値 | 役割                                                             |
| ------------------ | -----: | ---------------------------------------------------------------- |
| `HERO_DISTANCE`    |   0.65 | 最初の高度に切り替わるまでのスクロール距離（画面高に対する比率） |
| `SCENE_DISTANCE`   |   1.05 | 各高度に割り当てる距離（同上）                                   |
| `COUNT_DURATION`   |    680 | 高度カウントの時間（ミリ秒）                                     |
| `SCENE_ZOOM_LIMIT` |   0.08 | 長時間表示した場合に緩やかに近づく拡大幅（8%）                   |
| `SCENE_ZOOM_TIME`  |  60000 | 拡大の時間係数（ミリ秒）。大きいほどゆっくり拡大                 |

旅程全体の長さはCSSの`.journey.is-animated`、VISIONの長さは`.vision.is-animated`で指定しています。場面数・距離を変更する場合は、最後の場面を読むための距離を残してください。

スクロールはブラウザー標準のままです。逆スクロール、ページ内移動、途中の高度への直接アクセス・再読み込みに対応しています。スクロール更新とは別に、高度の背景が表示されている間だけ`requestAnimationFrame`で拡大します。初期設定では約10秒で1.2%、30秒で3.1%拡大し、その後も速度を緩めながら拡大を続けます。タブが非表示の間は一時停止し、復帰時に途中の大きさから再開します。

VISIONが画面へ入り始める時点で月面背景の拡大を止め、その大きさをDOMAINまで維持します。同じ月面へ戻ると途中から再開し、別の高度へ切り替えると新しい背景は拡大率1から始まります。背景のフェード中は、消えていく画像の大きさを保ちます。

OSの「視差効果を減らす」等が有効な場合と、十分な表示高を確保できない横向き等では、固定演出を解除して各場面を通常の縦並びで表示します。動きを減らす設定ではタブのフェード、背景拡大、セクションの出現、ホバーの移動を省略します。JavaScript無効時も全場面・全SIDE・DOMAIN・NEWSの内容と、標準HTMLの詳細開閉を利用できます。

- Firefox、WebKit：393／1512px幅。WebKitはSafari系の描画エンジンによる確認で、iPhone実機のSafariを実測したものではありません。
- 画像・フォントの読み込み、横はみ出し、6高度の同期、逆方向移動、VISIONでの固定解除、3タブと矢印、4詳細の開閉、キーボード操作、途中位置での再読み込み、動きを減らす設定を確認。
- JavaScript無効での本文表示と、`file://`で直接開いた場合の表示・SIDE切り替えを確認。
- Console Error、画像パス切れ、ページ内リンク切れ、外部アセットへの通信は検出されていません。

公開サーバー、導入先の共通部品、実機iOS／Android、Edge自体での確認は未実施です。元デザインどおりの赤い小文字（高度の英文・VISIONラベル）は、黒とのコントラスト比が約3.72:1で、WCAG AAの通常文字の基準4.5:1には達していません。ブランド色を維持しており、サイト全体のWCAG適合を保証する納品ではありません。

## 共通ヘッダー差し替え時の固定表示

`css/style.css`の`--header-height`はPC 112px／コンパクト表示72px、`--page-nav-height`はPC 64px／SP 56pxです。導入先の共通ヘッダーの高さが変わる場合は、これらの値も合わせて更新してください。ページ内メニューはHeroの外側に配置し、Heroのフェードや表示状態の切り替えから独立させています。

## 高度表示の固定位置

`.altitude-readout`は各`.altitude-scene`の外側に一つだけ配置しています。画面の上下・左右とも50%を基準に中央配置し、数値欄には一定の幅を確保して桁数が変わってもラベル位置が動かないようにしています。スクロールの切り替えでこの要素を作り直したりフェードさせたりせず、数値テキストだけを更新します。

JavaScript無効時や動きを減らす表示では、共通表示を隠し、各場面に元からある高度表示を通常の文章の一部として表示します。

## 月面背景の連続表示

`.lunar-scope`は高度体験からDOMAINまでを囲み、`.lunar-backdrop-stage`が画面サイズの月面背景を維持します。38万kmの表示開始時に背景を出し、VISION・DOMAINでは同じ要素と引き継いだ拡大率をそのまま使います。PC／SPの切り取り位置は`.lunar-background`で設定しています。VISION内で新たに拡大する演出や、DOMAIN専用の画像の繰り返しはありません。

EARTH × SPACEは指定されたSIDE背景を共通背景の手前に表示します。DOMAINの詳細を開いてページが長くなっても背景サイズは変わりません。共通背景はDOMAINの終端までとし、NEWSに引き継ぎません。動きを減らす設定・短い画面・JavaScript無効時も月面画像を共用し、本文は通常の縦並びで表示します。
