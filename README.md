# JTB × 宇宙 — 納品ファイル

2026年9月10日作成。ビルド不要のHTML・CSS・JavaScriptと、画像・SVG・Webフォントの一式です。

## 表示方法

`index.html`をブラウザーで開くと表示できます。Webサーバーに配置する場合は、**このフォルダーの中身を階層ごと**アップロードしてください。サブディレクトリーへの配置にも対応しています。

Figma、Google Fonts、CDNなどへの通信は表示時に発生しません。React、Next.js、jQuery等は使用していません。

```text
site/
├── index.html
├── css/
│   ├── style.css      共通値・基本スタイル
│   ├── corporate.css  共通ヘッダー・フッター
│   ├── sections.css   EARTH × SPACE〜CONTACT
│   └── intro.css      月面背景・FV・高度体験・VISION
├── js/main.js
├── assets/
│   ├── images/    写真・透過ロゴ（WebP）
│   ├── icons/     Figmaのベクターアセット（SVG）
│   └── fonts/     WOFF2と各書体のライセンス
└── README.md
```

## 実装内容

- FV〜VISION終了をFigma `2067:1229`に合わせて更新後、指定の調整を反映しています。各高度の見出し・中央コピー・英文は、場面が切り替わると同時に、それぞれ一文字ずつ45ms間隔で自動表示されます。スクロールを止めても最後まで表示が進み、同じ場面内では再開しません。背景切り替え・数値カウントの距離と速度は維持し、背景の拡大は時間に応じて進みます。
- FV〜VISIONの背景・レイアウトは`.intro-scope`内に適用しています。追加指定により、DOMAINの4タイトルもZen Old Mincho Regularを使用しています。
- PCのFVは共有Figma `340:2`のバランスに合わせ、中央コピーを最大約38pxにし、ロゴ・コピー・英文のまとまりを画面中央より少し下に配置しています。SPのFVは維持しています。
- SPの高度体験は共有Figma `340:1776`（390 × 852）に合わせ、見出し17px・中央コピー31.8px／行間48.3pxのZen Old Mincho Bold、英文8px、2段の「地上から」「約 〇〇km」、左下の高度ナビを配置しています。背景の切り取り位置も指定フレームに合わせています。短い画面では同じ配置を縦中央基準で移動し、狭い幅や長いコピーは収まる範囲で文字サイズを補間します。文字出現・数値カウント・背景ズームの動作は維持しています。
- EARTH × SPACE・DOMAIN・NEWSは、表示領域へ入ると見出しから内容へ順にフェードアップします。一度表示した要素は再び隠しません。
- ホバー可能な環境では、SIDEのタブ・選択カード・矢印、DOMAINの詳細行、NEWSの各行に小さな移動・色・影の変化を付けています。
- PROJECT・CONTACTのCTAは、マウスオーバーで赤色を濃くし、ボタンが3px浮き上がります。カーソルは手の形になります。リンク設置後はキーボードフォーカスにも同じ演出と輪郭線を適用します。「動きを減らす」設定では移動とトランジションを停止します。

- 高度の背景画像は、各画像へ切り替わった時点から経過時間に合わせてゆっくり拡大します。スクロールを止めても拡大を続け、同じ背景内の逆スクロールでも縮小しません。次の背景は元の大きさから拡大を始めます。長時間停止しても構図が崩れないよう、拡大幅8%へ緩やかに近づく動きにしています。
- VISIONの最後の文章とEARTH × SPACEの間に、月面背景を保った余白を追加しました。

- 修正④：EARTH × SPACEの初期選択をCONNECTに変更。初回表示からCONNECTのタブ、カード、打ち上げ背景を同期します。
- 通常の本文はNoto Sans JPを使用。FV・PC高度の見出しと中央コピー・VISIONの文章・DOMAINの4タイトルはZen Old Mincho Regularです。SP高度の見出しと中央コピーは指定フレームに合わせBoldです。Gothic A1は表示時に読み込みません。
- ページ内メニューの黒い背景とぼかしを外し、透明背景に変更しました。
- 高度体験の大きなコピーは画面の縦中央に配置し、数値はその下の一定位置に表示します。PCの高度ナビは固定ヘッダー・メニューより下の表示領域を基準に縦中央、SPでは指定フレームに合わせ、左17px・下42pxの下部配置です。

- 38万km〜VISIONは今回のFigmaの月面背景を共有。DOMAINは今回の修正範囲外のため、既存の月面背景と動作を維持しています。

- 「地上から約 〇〇km」は高度体験の共通表示として中央コピーの下に固定。数値部分は全高度でブランドの赤を使用し、ラベルとkmは白です。背景・コピーのフェードから独立させ、ラベルと数値欄の位置を保ったまま数値のみを更新します。VISIONに進むと高度体験と一緒に固定を解除します。

- 共通ヘッダーは全区間で固定表示。TOP／VISION／DOMAIN／NEWS／CONTACTメニューも固定ですが、SPの高度体験中だけは最新の指定フレームに合わせ非表示にし、FVへ戻った時・VISION以降・動きを減らす表示では再表示します。
- ページ内移動時は固定領域を考慮して見出しの位置を調整します。VISIONは固定領域より下に文章を収めます。

- 同じHTMLをPC・SPで使用。本文は767px以下でSPレイアウトに切り替え、間の幅は自然に補間します。共通ヘッダーの外観は1199px以下でコンパクト表示になります。
- 画面高は最新の既存実装に合わせて`100svh`を維持し、非対応ブラウザーでは`100vh`へフォールバックします。
- スマホの演出中は写真を`100lvh`で描画し、旅路・VISION・共有背景の固定はCSSの`sticky`を使用します。スクロールごとのJavaScriptによる位置補正は行いません。月面は両区間で共有し、旅路の末尾では切り替えません。Safariの下部バー背面が単色になる問題は未解決です。
- Heroのコピー出現と、スクロールで前面の暗幕を薄くする演出。
- 地上→10km→25km→100km→400km→38万kmの背景切り替え、数値カウント、コピーの出現。
- 高度ナビは左側。選択中の高度を同期し、PCではアイコンが移動します。SPではアイコンを表示しません。
- SCROLL DOWNと縦書きのJTB × SPACE BUSINESSは高度体験の区間で追従し、VISIONに入るところで解除します。縦書きラベルはPCの高度体験が始まってから表示し、SPでは最新の指定フレームに合わせ非表示です。
- VISIONは一つの文章に対し、スクロール順に文字を明るくします。修正③により背景の拡大率は固定しています。
- EARTH SIDE／CONNECT／SPACE SIDEのタブと矢印で、カードと指定背景を一緒に切り替えます。初期選択はCONNECTで、自動再生はありません。
- DOMAINの4項目は独立して開閉でき、コメントに記載された詳細本文・想定領域を収録しています。

- CONTACTは共有Figma「サイトデザイン4稿」のお問い合わせ部分に合わせ、中央ロゴの下に見出しと説明文を2列で配置し、その下に中央揃えのCTAを設けています。767px以下では見出し・説明文を縦に並べ、背景画像はセクション全体を覆います。見出しはZen Old Mincho Bold、説明文はNoto Sans JPを使用。共通フッターの構成は維持しています。

## 確定済みの仮対応

**外部リンクは依頼どおり未接続です。** ページ内ナビ、高度ナビ、SIDE切り替え、DOMAIN開閉は動作します。

| 対象         | 納品時の状態・導入時の対応                                                                                     |
| ------------ | -------------------------------------------------------------------------------------------------------------- |
| NEWS         | 日付・カテゴリー・記事タイトルの外観。公開時に各記事のURLを設定                                                |
| PROJECT      | `data-link-pending="project"`のCTAをリンクに変更。指定元で確認した遷移先は `https://open-universe-project.jp/` |
| CONTACT      | `data-link-pending="contact"`のCTAを問い合わせ先へのリンクに変更。フォーム本体は対象外                         |
| 共通ヘッダー | `data-common-header`を付けた`header`を、導入先の既存コンポーネントに差し替え                                   |
| 共通フッター | `data-common-footer`を付けた`footer`を、導入先の既存コンポーネントに差し替え                                   |

未接続のCTA・共通部分は静的な要素です。空の`href="#"`、押しても反応しない仮ボタン、仮の検索・メニュー機能は設けていません。CTAを接続する際は外側の`span.cta`を`a.cta`に変更し、確定した`href`を設定してください。

## 文字・写真を修正する場所

- **記事・コピー**：`index.html`。`news-row`、`domain-item`などの名前を付けています。DOMを追加・修正した後にビルドする必要はありません。
- **セクションのスタイル**：ヘッダー／フッターは`css/corporate.css`、EARTH × SPACE〜CONTACTは`css/sections.css`、FV・高度体験・VISIONと共有月面背景は`css/intro.css`。各ファイル内でPC／SPと表示状態を調整します。CSSの読み込み順は`index.html`に記載した順序を維持してください。
- **デザイン共通値**：`css/style.css`冒頭の`:root`。色、幅、余白、フォント、角丸をまとめています。
- **高度の画像**：`intro-0km.webp`、`intro-10km.webp`、`intro-25km.webp`、`intro-100km.webp`、`intro-400km.webp`は各場面の`img`を差し替えます。0kmは支給PNGを元の解像度でWebP化しています。10km（「青い地球はまだ見えない」）は支給PNG `intro-10km-319b5f95.webp.png`を元の解像度（3000 × 1876）でWebP化しています。400km（「人類の次なる活動拠点へ」）は支給JPEG `AdobeStock_145779274.jpeg`を元の解像度（7000 × 3500）でWebP化しています。10km・400km・月面の画像は用途が分かるファイル名に揃え、HTMLの参照URLに更新日パラメーターを付けて更新前のキャッシュを避けています。FVも0kmと同じ`intro-0km.webp`と切り取り位置を使用します。`intro-moon.webp`（支給PNG `4d3cae2e-7525-4029-9685-3e06aaa0c117 2 (1).png`を元の解像度3872 × 2178でWebP化）は`.intro-lunar-image`で38万km〜VISIONに使用。既存の`moon-surface.webp`と`.lunar-background`はDOMAINの表示を維持するため残しています。
- **SIDEの背景**：`side-earth.webp`＝街並み、`side-connect.webp`＝スペースシャトル打ち上げ、`side-space.webp`＝地球と宇宙飛行士。
- **リンク接続後**：必要な外部リンク・共通コンポーネントの動作は、導入先の環境で確認してください。

## アニメーションの調整

`js/main.js`は、詳細開閉・セクションの表示演出・SIDE切り替え・文字分割・高度体験の順に初期化します。高度体験の中に、背景ズーム、数値カウント、VISION、ページ内移動、画面サイズの再計測をまとめています。

`initializeJourney`内の次の定数を変更できます。秒数・距離の詳細はデザインコメントに数値指定がなかったため、試作値です。

| 設定               | 現在値 | 役割                                                             |
| ------------------ | -----: | ---------------------------------------------------------------- |
| `HERO_DISTANCE`    |   0.65 | 最初の高度に切り替わるまでのスクロール距離（画面高に対する比率） |
| `SCENE_DISTANCE`   |   1.05 | 各高度に割り当てる距離（同上）                                   |
| `COUNT_DURATION`   |    680 | 高度カウントの時間（ミリ秒）                                     |
| `SCENE_ZOOM_LIMIT` |   0.08 | 長時間表示した場合に緩やかに近づく拡大幅（8%）                   |
| `SCENE_ZOOM_TIME`  |  16000 | 拡大の時間係数（ミリ秒）。大きいほどゆっくり拡大                 |

旅程全体の長さは`css/intro.css`の`.journey.is-animated`、VISIONの長さは`.vision.is-animated`で指定しています。場面数・距離を変更する場合は、最後の場面を読むための距離を残してください。

スクロールはブラウザー標準のままです。逆スクロール、ページ内移動、途中の高度への直接アクセス・再読み込みに対応しています。スクロール更新とは別に、高度の背景が表示されている間だけ`requestAnimationFrame`で拡大します。現在は約10秒で3.7%、30秒で6.8%拡大し、その後も速度を緩めながら拡大を続けます。タブが非表示の間は一時停止し、復帰時に途中の大きさから再開します。

VISIONが画面へ入り始める時点で月面背景の拡大を止め、その大きさをDOMAINまで維持します。同じ月面へ戻ると途中から再開し、別の高度へ切り替えると新しい背景は拡大率1から始まります。背景のフェード中は、消えていく画像の大きさを保ちます。

OSの「視差効果を減らす」等が有効な場合と、十分な表示高を確保できない横向き等では、固定演出を解除して各場面を通常の縦並びで表示します。動きを減らす設定ではタブのフェード、背景拡大、セクションの出現、ホバーの移動を省略します。JavaScript無効時も全場面・全SIDE・DOMAIN・NEWSの内容と、標準HTMLの詳細開閉を利用できます。

## 共通ヘッダー差し替え時の固定表示

`css/style.css`の`--header-height`はPC 112px／コンパクト表示72px、`--page-nav-height`はPC 64px／SP 56pxです。導入先の共通ヘッダーの高さが変わる場合は、これらの値も合わせて更新してください。ページ内メニューはHeroの外側に配置し、Heroのフェードや表示状態の切り替えから独立させています。

## 高度表示の固定位置

`.altitude-readout`は各`.altitude-scene`の外側に一つだけ配置しています。横中央・大きなコピーの下に固定し、数値欄には一定の幅を確保して桁数が変わってもラベル位置が動かないようにしています。縦位置は`.intro-scope .journey-stage`の`--altitude-readout-top`で調整できます。スクロールの切り替えでこの要素を作り直したりフェードさせたりせず、数値テキストだけを更新します。SPでは数値部分を固定幅（3.2em）で中央揃えにし、桁数やカウント途中の小数表記が変わっても「約」と「km」の位置が変わらないようにしています。

JavaScript無効時や動きを減らす表示では、共通表示を隠し、各場面に元からある高度表示を通常の文章の一部として表示します。

## 月面背景の連続表示

`.lunar-scope`と`.lunar-backdrop-stage`は既存のDOMAIN用背景を維持しています。その内側の`.intro-scope`はFV〜VISION終了だけを囲み、`.intro-backdrop-stage`に最新の月面画像を表示します。38万kmでは両背景の拡大率を同期し、VISIONへ入ると停止。新しい背景はVISIONの終端で終わり、DOMAINは従来の画像・拡大率を使います。最新の月面画像のPC／SPの切り取り位置は`.intro-lunar-image`で調整できます。

EARTH × SPACEは指定されたSIDE背景を共通背景の手前に表示します。DOMAINの詳細を開いてページが長くなっても背景サイズは変わりません。共通背景はDOMAINの終端までとし、NEWSに引き継ぎません。動きを減らす設定・短い画面・JavaScript無効時も月面画像を共用し、本文は通常の縦並びで表示します。
